Why the extracted PSRR looked so different

The discrepancy has both extraction and physical causes. The revised layout produces about 47.2 dB at 3.3 V and 52.2 dB at 5 V in the capacitance-conserving RCC approximation. Most of the improvement over the old 39.3 / 42.4 dB report comes from correcting extraction. The physical routing change adds about 0.24 / 0.25 dB when measured with the same corrected model. The remaining 3.3 V gap to the schematic is about 3.36 dB.

What caused the discrepancy

  1. Old sidewall-capacitance coefficient. The installed Magic 8.3.678 predates the official correction. On the identical GDS, Magic 8.3.685 changes raw-RC minima from 39.25 / 42.40 dB to 40.99 / 44.37 dB. The KLayout-PEX documentation identifies the version issue, and the official Magic change explains the coefficient correction.
  2. Raw RC does not conserve the capacitance-only network. Removing every wire resistor from raw RC still leaves the large midband loss. Magic's resistance extractor converts coupling capacitance into grounded rnode capacitance while its RC export retains coupling capacitors. For example, baseline pm1 has 58.74684 fF summed coupling and 58.74685 fF in its added grounded rnodes. This is supported by the generated files and the official ResReadCapacitor source. Measured evidence.
  3. Residual physical coupling into the amplifier. With the corrected capacitance-only model, removing the AVDD–xf2 coupling diagnostically raises the 3.3 V minimum from 46.93 to 49.57 dB; removing AVDD–vgn2 raises it to 48.95 dB. These counterfactuals identify sensitivity, not achievable layout performance. Supply ripple is coupled into internal amplifier nodes and changes the closed-loop AC response around 20–30 kHz. Wire resistance is a smaller contributor to the minimum, although it affects DC supply rejection and output voltage.

Physical changes retained

  • Move the long vgn2 M4 route onto M5, with thirteen added via transitions and M4 retained at the connection points.
  • Keep the 2 µm top-metal supply straps 3 µm away in projection from sensitive amplifier wiring. Lower-metal supply connections remain complete where optional reinforcement cannot reach.
  • Apply the correct 0.46 µm top-metal spacing when building supply straps. Retain all device sizes, trim circuitry, matched-array positions, and schematic connections.

A more compact macro placement also passed DRC/LVS but worsened corrected PSRR to 44.30 / 49.41 dB and shifted VREF upward by about 2.3 mV. It was rejected. A lower-metal supply detour was tested and also not retained. The selected routing has a small tradeoff: low-frequency PSRR changes from 81.57 / 71.63 dB to 80.73 / 71.13 dB, while worst-band rejection improves. The nominal VREF shift relative to the previous physical layout is about 64 / 81 µV.

How the corrected model is bounded

The new adapter preserves every extracted device and interconnect resistor, then makes each original net-pair capacitance total equal to the capacitance-only extraction of the same GDS. Relative capacitance distribution along a wire uses the raw extractor's weights and remains approximate. It does not tune capacitor values to improve PSRR. Both raw and adapted models are delivered.

The adapter checks every capacitance pair. Independently, collapsing all interconnect resistances reproduces the C-only PSRR curve within a 0.001 dB tolerance at all 481 frequencies and both supplies. AC consistency check · Capacitance audit.

Floorplan and physical scope

The complete TB10 trim-inclusive IP core still contains 272 device units, seven trim controls and eleven MIM capacitors. Device placement is unchanged by the retained PSRR revision. The core occupies 614.0 × 307.6 µm.

This remains a core candidate, not a tapeout-qualified submission. Ground resistance is still omitted because the raw extractor falsely joins the isolated grounds. The conserved RCC distribution needs independent extraction confirmation. Full stability, noise, mismatch, corner startup, calibrated trim, pad/multiplexer loading, device-voltage and EM/IR qualification remain open. Matching edge dummies and matched route refinement remain open as well.

No public slot has been assigned. The public wrapper script specifies 537.15 × 273 µm, while the checked-in wrapper scales to about 619.785 × 315 µm with the pinned Magic PDK. This core does not fit the smaller envelope. The Chipalooza #3 rules and public harness govern final integration. The #2 rules provide integration precedent but use a different PDK. No slot, pad assignment, or final wrapper connection has been invented.
