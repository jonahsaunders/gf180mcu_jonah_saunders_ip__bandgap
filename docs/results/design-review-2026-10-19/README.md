# 1k design-review smoke checks — 2026-10-19

These reports characterize the revised 1k schematics with the readable runner.
They were generated by actual Xschem netlisting and ngspice simulation using
GF180MCU-D in the installed `hpretl/iic-osic-tools` image. No model patches or
threshold changes were made. [Provenance](provenance.json) records source and
report hashes. The baseline 2k build is preserved on `design_review_1`.

All ten testbenches completed: **16 case bundles**, with no execution failures
or simulator warnings reported by the runner. TB01–TB09 used `smoke`; TB10 used
`trim_nominal` including startup. These profiles are much smaller than the
full PVT matrix. A report's `full_grid_complete` refers only to its configured
profile; it does not certify the full design.

TB10 uses the existing 1.194 V calibration objective at 25 °C, not the separate
minimum-temperature-drift method. Full corner coverage, temperature-based code
selection, mismatch and extracted-layout performance remain to be rerun. The
reports preserve all parsed metrics; per-case raw waveforms are not included
in this compact evidence package.

To reproduce, select GF180 in the same shell, netlist each matching testbench,
then use `--profile smoke` for TB01–TB09 and `--profile trim_nominal` for TB10.
Use a fresh `--results-root` as described in the
[simulation guide](../../SIMULATION_GUIDE.md).
